GT-IconScaler v2.2

مولّد أيقونات احترافي مفتوح المصدر — من ملف PNG واحد إلى 38 مقاس عبر 8 منصات (Linux، PWA، Android، iOS، watchOS، Windows، Electron، macOS). بنية Bash نقية، ثنائية اللغة، نسختان (طرفية وZenity). Professional open-source icon generator — from a single PNG file to 38 sizes across 8 platforms (Linux, PWA, Android, iOS, watchOS, Windows, Electron, macOS). Pure Bash, bilingual, two versions (CLI and Zenity GUI).

⚙️ Bash + ImageMagick 🌐 عربي / English 🌐 Arabic / English 📦 GPLv3 🐧 Linux
⚡ التثبيت السريع ⚡ Quick Install 📦 على GitHub 📦 On GitHub

التثبيت بأمر واحد Install in one command 

bash <(curl -sSL https://raw.githubusercontent.com/SalehGNUTUX/GT-IconScaler/main/install.sh)
bash <(curl -sSL https://raw.githubusercontent.com/SalehGNUTUX/GT-IconScaler/main/install.sh) --cli -y
bash <(curl -sSL https://raw.githubusercontent.com/SalehGNUTUX/GT-IconScaler/main/install.sh) --gui -y
bash <(curl -sSL https://raw.githubusercontent.com/SalehGNUTUX/GT-IconScaler/main/install.sh) --all -y

💡 المثبّت يكتشف مدير الحزم تلقائياً (apt/dnf/pacman/zypper/apk) ويُثبّت الاعتماديات الناقصة. أضف sudo للتثبيت النظامي. لإلغاء التثبيت: استبدل install.sh بـ uninstall.sh في الأمر أعلاه. 💡 The installer auto-detects your package manager (apt/dnf/pacman/zypper/apk) and installs missing deps. Prefix with sudo for system-wide install. To uninstall: replace install.sh with uninstall.sh in the command above.

المميزات الرئيسية Key Features

📐

38 مقاس عبر 8 منصات 38 sizes across 8 platforms

تغطية شاملة من 16px إلى 1024px لكل احتياجات الأيقونات الحديثة. Comprehensive coverage from 16px to 1024px for every modern icon need.

🌐

ثنائي اللغة Bilingual

عربي وإنجليزي بكشف تلقائي من LANG أو علم --lang=. Arabic and English with auto-detection from LANG or --lang= flag.

⚙️

Batch + JSON

وضع غير تفاعلي بـ 5 علامات، إخراج JSON واحد على stdout — مثالي لـ CI/CD. Non-interactive mode with 5 flags, single-line JSON output to stdout — perfect for CI/CD.

🖥️

نسختان Two versions

طرفية تفاعلية + واجهة Zenity رسومية، تتشاركان نفس المكتبة. Interactive CLI + Zenity graphical GUI, sharing the same library.

📦

Bash نقي Pure Bash

لا Node ولا Python — فقط Bash + ImageMagick. خفيف وقابل للتدقيق. No Node, no Python — just Bash + ImageMagick. Lightweight and auditable.

🎨

‎.ico و ‎.icns تلقائياً ‎.ico and ‎.icns automatically

توليد Windows multi-size ICO وmacOS ICNS من نفس المصدر. Generates Windows multi-size ICO and macOS ICNS from the same source.
