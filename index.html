GT-IconScaler v2.2

مولّد أيقونات احترافي مفتوح المصدر — من ملف PNG واحد إلى 38 مقاس عبر 8 منصات (Linux، PWA، Android، iOS، watchOS، Windows، Electron، macOS). بنية Bash نقية، ثنائية اللغة، نسختان (طرفية وZenity).

⚙️ Bash + ImageMagick 🌐 عربي / English 📦 GPLv3 🐧 Linux
⚡ التثبيت السريع 📦 على GitHub

التثبيت بأمر واحد

bash <(curl -sSL https://raw.githubusercontent.com/SalehGNUTUX/GT-IconScaler/main/install.sh)
bash <(curl -sSL https://raw.githubusercontent.com/SalehGNUTUX/GT-IconScaler/main/install.sh) --cli -y
bash <(curl -sSL https://raw.githubusercontent.com/SalehGNUTUX/GT-IconScaler/main/install.sh) --gui -y
bash <(curl -sSL https://raw.githubusercontent.com/SalehGNUTUX/GT-IconScaler/main/install.sh) --all -y

💡 المثبّت يكتشف مدير الحزم تلقائياً (apt/dnf/pacman/zypper/apk) ويُثبّت الاعتماديات الناقصة. أضف sudo للتثبيت النظامي. لإلغاء التثبيت: استبدل install.sh بـ uninstall.sh في الأمر أعلاه.

المميزات الرئيسية

📐

38 مقاس عبر 8 منصات

تغطية شاملة من 16px إلى 1024px لكل احتياجات الأيقونات الحديثة.

🌐

ثنائي اللغة

عربي وإنجليزي بكشف تلقائي من LANG أو علم --lang=.

⚙️

Batch + JSON

وضع غير تفاعلي بـ 5 علامات، إخراج JSON واحد على stdout — مثالي لـ CI/CD.

🖥️

نسختان

طرفية تفاعلية + واجهة Zenity رسومية، تتشاركان نفس المكتبة.

📦

Bash نقي

لا Node ولا Python — فقط Bash + ImageMagick. خفيف وقابل للتدقيق.

🎨

‎.ico و ‎.icns تلقائياً

توليد Windows multi-size ICO وmacOS ICNS من نفس المصدر.
